# 日々

端末の中だけに保存される、オフラインの日記アプリ。

- 日記（その日のひとこと・できごと・気持ち・いい日/もったいない日）
- 毎日のルーティンのチェック
- 心に留めておきたいこと
- 観た・読んだ作品の記録

## 仕組み

HTML・CSS・JavaScript だけで動きます。書いた内容はすべて端末のブラウザの中（localStorage）に保存され、どこのサーバーにも送られません。

バックアップは JSON ファイルとして書き出し、別の端末で読み込めます。

## 使い方

iPhone の Safari で開き、共有ボタンから「ホーム画面に追加」。
アプリのように全画面で開き、電波がなくても使えます。
